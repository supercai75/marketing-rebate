1. 认证接口 /api/auth

提供用户登录、退出、当前用户获取、密码修改等功能。

1.1 用户登录

POST /api/auth?op=login
参数名类型必填说明
loginNameString是登录用户名
passwordString是登录密码

请求示例

{
  "loginName": "admin",
  "password": "123456"
}

出参

参数名类型说明
tokenString访问令牌，后续请求需在请求头中携带
user.idLong用户ID
user.nameString用户姓名
user.loginNameString登录用户名
user.isAdminInteger是否管理员(1=是,0=否)
user.permCodesArray权限码数组
user.roleCodesArray角色代码数组

响应示例

{
  "code": 0,
  "msg": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1,
      "name": "系统管理员",
      "loginName": "admin",
      "isAdmin": 1,
      "permCodes": [],
      "roleCodes": []
    }
  }
}
提示： 登录成功后，请将返回的token值放入后续所有请求的Header中：X-Token: <token值>

POST /api/auth?op=logout
参数名类型必填说明
